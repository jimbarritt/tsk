Harnesses: a code worktree, a tmux session and `claude` together, made and managed by `tsk harness` (M-TSK-ENV T-31; design in `docs/design/session-and-harness-flows.md`).

- **`tsk harness new`** asks whether to pick up a paused thread (listed as mission ID, robot and thread ID), else whether to attach an existing robot, else makes a new one; then a mission or a new mission. It makes a code worktree at `<worktree root>/<repo>/<name>` on the branch `harness/<name>`, copies the ignored `.env` files from the main worktree, opens a tmux session named after the mission, and starts `claude` with a first prompt. The new session finishes the set-up: it registers or constructs the robot, creates a new mission, and resumes or starts the thread. Flags (`--thread`, `--robot`, `--new-robot`, `--mission`, `--new-mission`, `--name`, `--no-claude`, `--no-attach`) skip the questions.
- **Names** are words from a list of 992 animals and insects in the binary, unique per clone. A deleted name is retired. When every word is used, a digit is appended. The terminal instance key is `<clone-id>/<name>`.
- **The worktree root** is `GIT_WORKTREES_ROOT`, else `[worktrees] root` in the user config (`tsk config worktrees-root [<path>]`), else `tsk harness new` stops and names both. There is no built-in default.
- **`tsk harness list`** shows name, robot, mission, thread, awake or asleep, and directory. `tsk harness path <name>` prints the directory; a unique prefix of the name is enough.
- **`tsk harness sleep`** pauses the harness's thread and stops its tmux session; the worktree stays. **`tsk harness wake`** starts the session again and resumes the thread in `claude`. **`tsk harness delete`** stops the session and removes the worktree; it refuses while the worktree has changes or the branch has unpushed commits, unless `--force`.
- **`tsk harness cd <name>`** changes your shell's directory through a shell function: `tsk shell-init zsh` prints it, and `tsk install zshrc` adds `eval "$(tsk shell-init zsh)"` to `~/.zshrc` once. A program cannot change the directory of the shell that started it, so the function does the `cd`.
