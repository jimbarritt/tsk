A thread's mission is its current focus (ADR 0031, M-TSK-ADHOC T-47 to T-50). A change of mission keeps the thread, and a thread is created only for a harness instance with no bound thread and no thread to join. The ledger stays at layout 14.

- **`/tsk:switch-mission` is new.** It checks the binding, pauses on the old focus with `tsk thread pause --bound`, runs `tsk thread set mission`, and sets the session title. The thread stays the same.
- **`/tsk:start-thread` runs only when nothing is bound.** It has no natural-language trigger now. It offers existing threads to resume before it creates one, and a bound session gets `tsk:switch-mission` or `tsk:resume-thread` instead.
- **`/tsk:switch-thread` keeps the thread left behind** for its actor to resume. It offers to stop that thread only when the line of work is finished.
- **`/tsk:resume-thread` names the current focus** of the thread in its summary.
- **The session start context** reads `The current focus of this thread is mission <id> (<status>): <name>.` in place of `This thread works mission ...`.
- Plugin 0.3.43. The plugin requires tsk 0.42.0 or later.
- Tests: the existing conformance test covers a pause that records the mission of the thread, a `thread set mission` that changes it, and a later pause that records the new one. The session start tests assert the new sentence. The full suite passes: 431 unit tests and 492 integration tests.
