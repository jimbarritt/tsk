This release makes the GitHub Copilot CLI hooks find the repo they run for.

- Copilot runs its plugin hooks outside the repo and names the repo in the `cwd` of the hook input. `tsk thread session-start --format copilot` and `tsk thread guard --format copilot` now change to that directory first. Before, session start printed "not inside a git repository", fetched no ledger and recorded no session.
- A Copilot session now has a `copilot-cli` row in `tsk session list`.
- The `session-end.sh` hook changes to the `cwd` of its input before it checks the ledger. The end of a Copilot session now publishes the ledger.
- Claude Code hooks are unchanged: they run in the project folder.
- The `tsk` plugin is at 0.3.75.
