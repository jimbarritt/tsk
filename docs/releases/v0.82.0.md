This release adds `tsk ledger emails`, `tsk ledger rewrite-emails` and `tsk ledger push-rewritten`.

- `tsk ledger emails` counts each author and committer email in the history of the data ref and the documents ref. `--porcelain` prints tab-separated lines.
- `tsk ledger rewrite-emails --to <noreply address>` rewrites the history so that every non-noreply email becomes the address. `--from <email>` limits the rewrite to named addresses. Trees, names, dates and messages stay the same. With the robot identity, each rewritten commit is signed with the robot key. The command changes local refs only and pushes nothing. Without `--yes` it prints the plan and exits 1.
- After a rewrite, the command prints the old and new tip of each ref and the push command. It also lists the clones on this machine that share the ledger home.
- `tsk ledger push-rewritten --yes` force-pushes both refs in one atomic push with a lease on each old tip. If origin moved, nothing changes. An agent stops for the person's confirmation before this step.
- The documents branch gets the `.tsk-erased` marker with the command name. A clone with the old commits and no local work replaces its documents copy at the next fetch. A clone with the old commits and local work stops with an error.
- The rewrite does not change Dolt commit emails inside the data or `Co-authored-by` lines in messages. An older tsk can push the old emails back, so update every clone before the push.
- The plugin is at 0.3.73.
