This release lets an agent find the commit to erase, and erase one file by its path.

- `tsk ledger doc log [<ref>]` lists the commits of the local documents branch, newest first: the short id, the date, the author and the subject, tab-separated. With `<ref>`, a document path with or without its id, it lists only the commits that changed that file. It fetches nothing. The ledger guard blocks `git log` on the ledger refs, so this command is the way to find a commit id for `tsk ledger erase`.
- `tsk ledger erase --file <ref>` removes every version of one file from the whole documents history, with no commit id. It uses the same push, pruning and checks as `tsk ledger erase <commit>`. A file that is no longer on the branch is named by its full path.
