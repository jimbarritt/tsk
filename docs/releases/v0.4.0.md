GitHub Copilot CLI support.

- `tsk install-plugin copilot-cli` installs the tsk plugin into GitHub Copilot CLI from the marketplace in this repo, `tsk@tsk`.
- The plugin's Copilot hooks run the session start and the thread guard. `tsk thread session-start --format copilot` prints Copilot's output shape.
- Untested in a live Copilot session.
