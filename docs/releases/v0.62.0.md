The robot and the work are chosen in one question round, and every session gets its title.

- **One question round.** With no thread binding and no robot, `tsk thread next` and the Stop hook ask the robot and the work in one `AskUserQuestion` call with two questions: the robot, then the latest thread of each robot offered, missions for a new thread, and "No thread".
- **The title line after a choice.** In a cloud session, `tsk actor register` and `tsk thread skip` print the `Session title:` line with the `session_...` ID and the title, so the agent sets the title with no ID to type.
- **NO-MISSION titles.** A session whose thread has no mission, or that has no thread, is titled `NO-MISSION: <robot>`. `tsk thread title` prints the same.
- **Plugin 0.3.61:** the skills describe the `NO-MISSION` title.
