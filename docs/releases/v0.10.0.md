Task, decision and question records.

- Tasks, decisions and questions are typed rows in the Dolt ledger, written only through `tsk task`, `tsk decision` and `tsk question` commands. `tsk task` has `add`, `set`, `block`, `unblock` and `list`. `tsk decision` has `add` and `list`. `tsk question` has `add`, `answer` and `list`.
- A task ID is `T-nn` and a question ID is `Q-nn`. Each mission mints its own numbers with a counter that only grows. Blocked state of a task is derived from the status of the tasks that block it. `tsk mission list --json` carries the tasks, decisions and questions of a mission.
- A new Dolt ledger is manifest version 4. A version 3 ledger reads as a ledger with no tasks, decisions or questions, and its first mission, task, decision or question write adds the counters to `missions`, creates the tables and sets version 4. A tsk from before this release stops at a version 4 ledger with `unsupported ledger version 4`: update it. `tsk ledger migrate-docs` and `migrate-to-dolt` now create version 4 ledgers.
- The file ledger keeps tasks, decisions and questions in the mission's file in `records/missions/`. Its manifest stays version 1.
