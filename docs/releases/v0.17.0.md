Dolt 2.5.0, fewer network costs, and the first small clean-ups after M-TSK-SCHEMA.

The pinned Dolt moves from 1.88.2 to 2.5.0. The plugin's `SessionStart` hook installs 2.5.0 when no Dolt 2.5.0 or later is installed. Clones on 1.88.2 and 2.5.0 push to and fetch from each other without trouble, and the suite passes on both.

## Speed

- **Dolt 2.5.0.** A fetch with nothing new launches 456 `git cat-file` processes, from 1,362 on 1.88.2, on the same 227-file remote.
- **Git protocol version 0** for the git processes tsk starts, and the ones Dolt starts for tsk, through `GIT_CONFIG_COUNT`. A live `tsk ledger fetch` with nothing new takes 1.9 s, from 2.65 s. A `protocol.version` the user sets stands. `TSK_GIT_PROTOCOL=default` turns it off.
- **The update check runs once a day.** The time of the last check and its result are cached in `${XDG_STATE_HOME:-$HOME/.local/state}/tsk/update-check`. A session start inside the day makes one network operation fewer. `TSK_UPDATE_CHECK=always` and `=never` override it. `tsk self-update` still asks the network every time.

## Lists and commands

- `tsk mission list`, `task list`, `decision list` and `question list` print columns padded with spaces, with no tabs. `--porcelain` prints the tab-separated lines of earlier releases. JSON is unchanged. The session start context keeps tabs, because an agent reads it.
- `tsk decision list` with no arguments lists every decision of every mission, with the mission ID first.
- `tsk question add --on <date>` and `tsk question answer --on <date>` set the dates.
- `tsk thread prune-bindings [--older-than <days>] [--dry-run]` removes the bindings of cloud sessions older than the age (30 days by default). It keeps worktree bindings and the current session's. It is a local write: `tsk ledger push` publishes it.
- A pause entry's `written_by` holds the actor key (the session ID, or `<clone-id>/<worktree-name>`), so two clones' main worktrees read as two writers. Entries written by 0.16.0 or earlier hold `urn:tsk:worktree:.git`, and count as an unknown writer: they never raise a takeover warning.
- `tsk` piped to a program that closes early, such as `tsk thread list | head -1`, ends quietly.
