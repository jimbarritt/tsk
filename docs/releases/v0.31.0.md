A ledger has a mission prefix (ADR 0027). `tsk mission create` and `tsk mission mv` add it to an ID that lacks it, and a number at the end of an ID marks a part of a mission. The ledger is still at layout 10.

- **`tsk mission prefix [<PREFIX>]`** prints the mission prefix of the ledger, or sets it. A prefix is 3 or 4 capital letters, such as `TSK`. It is the manifest key `mission_prefix`, a row of the `manifest` table, so it reaches every clone with the ledger and does not change when a repo is renamed. With no argument and no prefix it exits 1 and says how to set one. Setting it renames no mission. Two clones that set the same value merge.
- **`tsk mission create` adds the prefix** after `M-` to an ID that lacks it: `M-BOOT` becomes `M-TSK-BOOT`. It prints the resulting ID on stdout and a note on stderr when it added the prefix. An ID that starts with `M-TSK-`, or is `M-TSK`, is not changed. Another group of capital letters, such as `M-LAB`, counts as a name: `M-TSK-LAB`. A ledger with no prefix works as before and prints a note on stderr when it already has missions.
- **A trailing number is for a part of a mission.** With a prefix, `M-TSK-BOOT-01` has to be a part of the mission `M-TSK-BOOT`, which has to exist. `create` makes it the parent when none is given, and refuses a different parent. A separate mission of the same kind gets a name, not a number.
- **`tsk mission mv`** adds the prefix to the new ID in the same way, and refuses a number whose mission is not the parent the mission has, or is the mission being renamed. A part is renamed after its parent.
- **Not built:** the check against the other ledgers of a nexus when a ledger is registered (ADR 0027, decision 4). It is M-TSK-ADHOC T-32.
- Tests: `cli/src/mission/prefix.rs` (the prefix, the number rule) and `cli/tests/conformance.rs` (set, read, merge, create, mv and the refusals).
- The plugin is 0.3.27 and requires tsk 0.31.0. The `tsk` and `start-thread` skills and `tsk guide import` name the prefix.
- Documents: ADR 0027, `docs/domain/ledger-layout.md`, the user guide.
