The `Stop` hook publishes in the background and no longer asks the agent to push (ADR 0020). Asking cost a model turn and its tokens on every turn that wrote a record. The default idle stop of the local Dolt server is now 30 minutes.

- **`tsk ledger push --background [message]`.** With nothing unpushed, or while another push holds the push lock, it exits 0 at once with no output. Otherwise it starts a detached one-shot child (`tsk ledger background-push-run`, its own session, output in `background-push.log`) that runs the normal push and returns. The message defaults to `Background publish`. The child is not a daemon: no socket, no loop, no state beyond the lock and the result file.
- **One push at a time.** `push.lock` in the state directory of the clone is an `flock` that the child inherits, so the kernel frees it when the child ends or is killed. `tsk ledger push`, `thread start`, `pause` and `stop` take it too, waiting up to 60 s (`TSK_PUSH_LOCK_SECS`).
- **The result file.** `background-push.result` records `running`, `ok` or `failed`, the time, the commit and the error. A `running` result with no lock holder reads as a failure named `interrupted`.
- **A failure shows once as a warning.** The next `tsk` command that opens the ledger store, `tsk thread guard` and `tsk thread session-start` among them, prints `warning: the last background publish failed at <time>: <error>; run tsk ledger push` on stderr. Standard output is unchanged. A later push that succeeds clears it. `tsk ledger status` shows `Background publish: ok at <time>`, `failed at <time>: <error>` or `running`.
- **`tsk thread guard` publishes and prints nothing for unpushed work.** The unbound-thread check and its block decision are unchanged. `stop_hook_active` no longer affects the publish. `TSK_BACKGROUND_PUBLISH=off` switches the publish of the hook off.
- **Thread start, pause and stop, `tsk ledger push` and the `SessionEnd` hook stay synchronous.**
- **`tsk ledger status` names the local Dolt server.** `Server  running (pid 123, idle stop 1800 s)` or `Server  not running (switch off)`. It is in the normal and the `--local` output, not in `--porcelain`.
- **The default idle stop of the Dolt server is 1800 s** (it was 120 s). `TSK_DOLT_SERVER_IDLE_SECS` still overrides it. A working session should not see a restart, and a forgotten server still ends after 30 minutes. The choice is to be revisited (M-TIDY).
- **The skills, the guide and CLAUDE.md** say that the `Stop` hook publishes in the background and that a failure shows as a warning.

Run with the server on and off.
