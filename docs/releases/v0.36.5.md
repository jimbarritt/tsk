A `PreToolUse` hook stops an agent from changing the ledger without `tsk` (ADR 0028, M-TSK-ADHOC T-44). The ledger is still at layout 10.

- **The rule.** Every change to the ledger goes through the `tsk` binary, so the backend can change without touching a skill. An agent runs no `git` or `dolt` command against the ledger store, its refs or its branches, and edits no file in the ledger store.
- **The hook.** `tsk ledger guard` reads the hook input and prints a deny decision for a `Bash` call that runs `git` or `dolt` against `tsk/ledger`, `tsk/docs`, `tsk/bootstrap`, `refs/tsk/*` or a path in the ledger store, for any other `Bash` command that names a path in the ledger store, and for an `Edit`, `Write`, `MultiEdit` or `NotebookEdit` call on a file in the ledger store. It allows every `tsk` command and `git` in the code worktree.
- **Fails open.** The plugin script `hooks/pre-tool-use.sh` allows the call when `tsk` is missing, older than 0.36.5, or fails. A maintainer who runs `dolt` by hand sets `TSK_LEDGER_GUARD=off` in the environment that starts the agent.
- Plugin 0.3.37. The plugin now requires tsk 0.36.5 or later.
