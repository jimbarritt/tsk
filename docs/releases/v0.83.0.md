This release fixes `tsk` in environments that set `safe.bareRepository=explicit`, such as GitHub Copilot CLI.

- `tsk` runs `git` on a bare clone with `GIT_DIR` set to that clone. The nexus cache, the ledger home and the clones of `move-ledger`, `erase` and the history rewrite are bare clones. With `safe.bareRepository=explicit`, git fails on a bare clone that it finds from the current directory, and the nexus fetch failed.
- A linked worktree of a bare clone is not affected.
- A test fetches and pushes the nexus and a ledger with the setting on.
