The tmux sidebar (M-TSK-BOOT-06). A pane on the left lists every tmux session with its agent's state, mission and robot, and stays beside your work from session to session. The ledger stays at layout 14, and the plugin stays at 0.3.45.

- **`tsk tmux sidebar` is new.** It runs the list in a pane. `j` and `k` select, `Enter` or a digit switches to a session, and `q` closes it. The list refreshes every second.
- **`prefix b` opens it, focuses it, or closes it when it has the focus.** It runs `tsk tmux sidebar toggle`.
- **The sidebar follows you.** While it is open, the hooks `client-session-changed` and `session-window-changed` run `tsk tmux sidebar follow`, which puts the same pane into the new window with `join-pane`; the focus stays on your work.
- **`tsk tmux install` writes the binding and the hooks.** Run it again after the update to get them. `@tsk_sidebar_width` sets the width, 32 columns by default.
- User guide: [docs/user-guide/tmux.md](../user-guide/tmux.md).
- Tests: unit tests for the session rows, the sidebar pane, the list lines and the keys. A manual test on tmux 3.4 with a client that sends keys: `prefix b` opens the sidebar, after a session switch it is in the new session, `k` and `Enter` switch back, and `prefix b` twice closes it.
