Mission records.

- Missions are typed rows in the Dolt ledger, written only through `tsk mission` commands: `create`, `set`, `block`, `unblock`, `objective`, `link`, `unlink` and `list`. Blocked state is derived from the status of the blockers.
- A new Dolt ledger is manifest version 3. A version 2 ledger reads as no missions, and its first mission write creates the tables and sets version 3. `tsk ledger migrate-docs` and `migrate-to-dolt` now create version 3 ledgers.
- The file ledger keeps one JSON file per mission in `records/missions/`.
