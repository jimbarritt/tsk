`tsk mission mv` updates the link of every mission that links a document it renames. The ledger is still at layout 10.

- **The fault.** `tsk mission mv` renamed each linked document whose path names the mission and updated the link of the mission it renamed only. A document that another mission also links kept the old path in that mission's link. The push then stopped with `mission M-X links the document ..., which is not on the tsk/docs branch`. Found on 2026-10-25 when 24 missions were renamed with the prefix: two links of other missions pointed at moved documents.
- **The change.** The links of all missions that name a moved path follow it. The plan, and the output, gain one `link <mission> <new path>` line for each such mission, after the `doc` and `thread` lines and before the `mentions` lines.
- Tests: `cli/src/mission/mv.rs` (the link lines) and `cli/tests/conformance.rs` (a second mission links the document that is named for the renamed mission).
- The plugin does not change. It still requires tsk 0.31.0 or later.
