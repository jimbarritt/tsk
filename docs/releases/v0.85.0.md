This release lets `tsk config attribution` remove the `signing_key` and `signing_program` settings.

- `tsk config attribution --user --signing-key ""` removes `signing_key` from the config file. Before, an empty value was an error.
- `tsk config attribution --user --signing-program ""` removes `signing_program` in the same way.
- Together with `--signing-key-file ""`, a config that signed through the 1Password agent can switch to a key file with no hand edit.
- The `tsk` plugin stays at 0.3.74.
