The tmux session list shows every agent, the sidebar moves to `prefix B`, a task can name its ticket, and `tsk harness new` asks the branch name.

- **The session list.** tsk writes the state, the robot and the mission on the agent's pane and on its tmux session. The chooser reads the session's active pane, and a value missing on the pane falls back to the session, so a shell opened beside the agent still shows the agent's values. `tsk actor register` and `tsk actor remove` update the values at once.
- **Keys.** The sidebar is on `prefix B` by default, so `prefix b` stays free for the configs that use it to hide the status bar. `tsk tmux install --sidebar-key <key> --chooser-key <key>` chooses other keys and saves them as `[tmux] sidebar_key` and `chooser_key` in the user config. Run `tsk tmux install` again to write the new keys.
- **A task's ticket (layout 15).** A task gains `ext_tracking_id`, a URN of the form `urn:tsk:ext:ticket:<system>:<id>`, for example `urn:tsk:ext:ticket:linear:TEAM1-546`. `tsk task set <mission> <task> ext-tracking-id linear:TEAM1-546` sets it, and `none` clears it. `tsk task list` shows the ID in a last column, and `tsk mission list --json` prints the URN. The first write upgrades a ledger to layout 15, and an older `tsk` then updates itself.
- **The branch question.** `tsk harness new` asks the branch name last. Its suggestions, in order: the ticket ID of the thread's current task (for example `TEAM1-546`), mission and thread, mission and harness name, and a detached HEAD. You can also type a name. `--branch` and `--detach` answer it.
- **A pause in a detached worktree.** `tsk thread pause` accepts a detached HEAD whose commit is on an origin branch, and records that branch.
- **Tests stay out of tmux.** Every command the tests start drops `TMUX`, `TMUX_PANE` and `TSK_TMUX_BIN`, so a test run inside a tmux pane no longer renames the real session.
- **A test fixture updated its own binary.** The `migrate_docs` fixture did not set `TSK_AUTO_UPDATE=never`, so its test of an unknown ledger version made the test binary update itself to a release. The fixture now sets it.
