This release adds `tsk release-notes`, a `[features]` setting for optional features, and the `migrate-plan` skill.

- `tsk release-notes` prints the release notes embedded in the binary. With no argument it prints the installed version. `tsk release-notes <version>` prints that version, and `--since <version>` prints every later release, newest first. An unknown version exits 1. The top-level `--help` names the command.
- After a cloud session updates tsk, session start prints the old version and the command `tsk release-notes --since <old version>`.
- `[features] enabled` in the user config lists the optional features. `tsk config features` prints the list and the known features, `tsk config features software-english` sets it, and `--none` clears it. The only feature is `software-english`.
- With `software-english` enabled, session start installs the Software English commit check in the repo and each sibling checkout without it. Without the feature, session start installs nothing.
- `ops/cloud/setup-environment.sh` takes `--features <list>` and writes the list to the user config. It replaces the interim swe hook step. An environment that has the interim hook gets `software-english` enabled, and the script then removes the hook file and its `settings.json` entry. When the installed tsk has no `config features` command, the script keeps the hook and prints a warning.
- The `migrate-plan` skill imports old plan files. It accepts any plan format. The agent finds the planning material, proposes missions and tasks, and writes records with `tsk` commands only after the person confirms.
- The plugin is at 0.3.72.
