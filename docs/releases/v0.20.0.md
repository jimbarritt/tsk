A new ledger uses a custom ref by default.

- **Custom ref by default.** A new ledger lives on `refs/tsk/ledger` and `refs/tsk/docs`. GitHub does not list these as branches. A repo can still keep the ledger on branches (`refs/heads/tsk/ledger` and `refs/heads/tsk/docs`).
- **Resolution order.** `tsk` takes the refs from the `TSK_LEDGER_REFS` variable, then the nexus entry, then `[ledger] refs` in `.tsk/config.toml`, then discovery: the ledger store's recorded ref, a cached answer, then one `git ls-remote`. With no answer, the default is a custom ref, or branches in a Claude Code cloud session, whose proxy refuses custom refs.
- `tsk config ledger-refs` prints the refs in use and where the choice came from. `tsk config ledger-refs branches|custom` writes `.tsk/config.toml`.
- `tsk nexus register-repo --ledger-refs` records the choice in the nexus.
- This repo sets `refs = "branches"` in `.tsk/config.toml`, so nothing changes for it.
- Documents: ADR 0016.
