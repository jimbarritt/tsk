This release fixes the Copilot session start hook, which 0.86.0 did not repair.

- The `session-start.sh` hook of the plugin called `tsk` with no `--format` option for Copilot and converted the output itself. So the `cwd` change of 0.86.0 never ran. The script now reads the hook input once and changes to its `cwd`. It passes the input and `--format copilot` to `tsk`, and reads the Copilot output.
- A Copilot session start now fetches the ledger of the repo and records a `copilot-cli` row, visible in `tsk session list`.
- The `tsk` plugin is at 0.3.76.
