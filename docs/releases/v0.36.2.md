A `/tsk:regenerate-cloud-instance` skill (M-TSK-ADHOC T-37). The ledger is still at layout 10.

- **The fault.** A cloud session keeps the plugin, hooks and `tsk` binary it started with, and a plugin update does not reach it. The only fix was to open a new session by hand and bind it to the thread.
- **The skill.** `/tsk:regenerate-cloud-instance` reads the thread, the robot name and the title, pauses the thread and pushes the ledger, then starts a new cloud session with `create_session`. The prompt of the new session resumes the thread, joins the existing robot with `tsk actor register`, and sets the same title. The skill then sets the title of the old session to `to archive- <title>`. It does not archive the old session.
- Plugin 0.3.34. The plugin still requires tsk 0.36.0 or later.
