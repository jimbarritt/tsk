The pause and regenerate skills leave the ledger to `tsk` (M-TSK-ADHOC T-43). The ledger is still at layout 10.

- **The fault.** `/tsk:pause-thread` told the agent to run `tsk ledger push` when the `ledger:` line of the pause reported unpushed changes. `/tsk:regenerate-cloud-instance` ran `tsk ledger push` after every pause. `tsk thread pause` pushes every record itself and exits 1 when the push fails, so both steps were redundant and put the agent in the ledger by hand.
- **The fix.** Both skills run no ledger command. A `ledger:` line other than `ledger: pushed` is an error to report. The agent still checks the code worktree.
- Plugin 0.3.36. The plugin still requires tsk 0.36.0 or later.
