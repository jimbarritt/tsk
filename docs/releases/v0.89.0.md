This release makes the integration tests pass on macOS. The set-up refresh of the plugin also runs on a machine with no `flock`.

- `plugin/hooks/refresh-setup.sh` takes its lock only when `flock` is installed. Without `flock`, which macOS lacks, the script printed a timeout warning and did not run. The `tsk` plugin is at 0.3.77.
- The integration tests resolve `/var` to `/private/var` before they compare paths. They list processes with `ps`, not `/proc`. They remove `TSK_UNATTENDED`, `TSK_SESSION` and `TSK_LEDGER_WT` from the environment of each `tsk` command.
