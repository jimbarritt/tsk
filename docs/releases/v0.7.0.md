A self-update command.

- `tsk self-update` upgrades tsk to the latest release by the method it was installed with: Homebrew, Cargo or a release binary. `--check` only reports.
- The session start context says when a newer release exists. `TSK_NO_UPDATE_CHECK=1` turns the check off.
- A cloud session that runs the hook with `--install-plugin` upgrades tsk before it installs the plugin.
