`tsk actor attach` attaches a session to an existing robot, and the first prompts of `tsk harness new` and `tsk harness wake` use it.

- **Attach an existing robot.** `tsk actor attach <name>` joins this session or worktree to the robot with that name. It prints `attached existing robot <name> (uid <uid>)`. It creates no actor, and exits 1 when no robot has the name. The first prompts of `tsk harness new` and `tsk harness wake` now run it for a robot that exists. The robot prompts of the session start name it too. A harness made before 0.68.1 takes its push workflow from the repository's push workflow setting at wake.
