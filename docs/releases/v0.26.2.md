A push with no documents hook is as fast as before the hook point (ADR 0025). The ledger is still at layout 9.

- **No hook, no extra git calls.** `tsk ledger push` looked for the documents hook after it had worked out the list of changed documents, which costs several git starts. It now looks for the hook first and works out the list only when a hook exists. With no `pre-docs-commit` script, the lookup is four checks for a file.
- The plugin does not change. It still requires tsk 0.26.1 or later.
