A ledger has a scratch directory for input documents that stay out of the ledger and out of source control (M-TSK-ADHOC T-57). The ledger stays at layout 14.

- **`tsk ledger scratch` is new.** It creates the scratch directory when it is missing and prints its path.
- **`tsk ledger fetch` creates the directory**, so every clone has it after its next fetch. `tsk ledger path` has no side effects and does not create it.
- **The directory is `<state>/repos/<clone-id>/scratch`**, beside `ledger-db` and `docs`. It is outside the Dolt database and outside every git worktree, so Dolt and git ignore it without a rule. `tsk ledger push`, `status` and `discard` do not see it.
- **Use it for** full meeting transcripts, Slack conversations and documents from the internet.
