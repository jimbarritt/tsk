`tsk harness wake` resumes the claude session of a harness.

- **Session resume.** `tsk harness new` starts claude with `--session-id` and records the ID in the harness state. `tsk harness wake` starts claude with `--resume <id>` when the state has an ID and the transcript of that session exists. Otherwise it starts a new session with a new ID and records it. The first prompt of `wake` registers the robot and resumes the thread on both paths. A state file with no ID still loads. For example, after a restart of the machine, `tsk harness wake my-harness` returns the earlier conversation.
