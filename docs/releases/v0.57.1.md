A resume summary names the right task after a thread changes mission.

- **The task of the latest pause entry.** `tsk thread resume` and session start look the task up in the mission the entry names, not in the thread's current mission. When the two differ, the task label names the entry's mission, for example `M-OLD T-01`. Before, a pause written on one mission and read after `tsk thread set mission` showed the task of the same number in the new mission.
- **Tests:** a conformance test that pauses on one mission, sets another, and checks the task of the resume output.
