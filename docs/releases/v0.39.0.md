The ledger is at layout 12: an actor belongs to a session, and a harness instance is the continuity key (ADR 0030, M-TSK-ADHOC T-33 and T-35). The ledger changes at the first write by this `tsk` that needs the new layout. A `tsk` older than 0.39.0 then stops with `unsupported ledger version 12`. From 0.18.0 a `tsk` updates itself and runs the command again. A session start never upgrades.

- **`thread_bindings` replaces `bindings`.** The key column is `instance`, the key of a harness instance. The upgrade copies every row and drops the old table.
- **An actor has a `uid`, and its name can change.** `tsk actor register` mints the uid for a new name and prints `urn:tsk:actor:<uid>` on a second line; the upgrade derives one from each existing name, so two clones that upgrade on their own write the same value. `actor_names` keeps every name an actor has held. `tsk actor list` prints the uid, and `--json` adds the URN and the name history.
- **A session has actors.** `session_actors` holds one primary and any number of supporting actors for each recorded session. `tsk actor register` makes the registering actor the primary of the current session. `tsk actor join <uid> [--primary] [--session <urn>]` adds an actor, for example the human who supervises a robot's session. `tsk session actor` lists them. `tsk actor name` prints the primary actor's name, else the actor of the latest session of this instance, else the one the instance registered as. The upgrade gives every recorded session the actor its instance had registered as.
- **A pause names the session that wrote it.** `written_by` holds the session URN. The takeover warning compares actors: the same robot in a regenerated cloud session does not warn, another actor does, by name. A terminal session's URN is kept in the local file `tsk-session` of the git directory, written at session start.
- **A new session takes its actors from the session it continues**: the one that wrote the latest pause on the bound thread from the same instance, else the latest recorded session of the instance. The session start context prints `Bindings:` with the session URN, the instance URN and the actors.
- **The ledger has an ID.** The manifest key `ledger_id` is minted for a new ledger and derived from the root commit at the upgrade. `tsk ledger id` prints `urn:tsk:ledger:<ledger-id>`; `tsk thread list` and `tsk mission list --json` print `urn` (`urn:tsk:thread:<ledger-id>:<thread-id>`, `urn:tsk:mission:<ledger-id>:<internal-id>`). The scheme is `docs/domain/urn-scheme.md`.
- **`tsk ledger status`** labels the upgrade and hides the rows it copied.
- Plugin 0.3.40: the `tsk` skill describes the model and the new commands, and the start-thread skill adds a supervising human with `tsk actor join`. The plugin requires tsk 0.39.0 or later.
- Tests: three conformance cases (the upgrade on two clones and their merge, the continuity of actors across a `/clear` with the takeover warning by name, and `tsk actor join`), the writers resolver, and every older layout fixture taken through layout 11.
