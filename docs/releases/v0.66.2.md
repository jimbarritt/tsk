`tsk` prints a progress line when it fetches the nexus index in a terminal.

- **Progress line.** A command fetches the nexus repo before it resolves the ledger location. In a terminal it prints `fetching the latest nexus index from <url>...` on stderr first. Piped or captured stderr stays quiet, so hooks add nothing to session context. The fetch still runs on every command.

Found while measuring `tsk mission list` (M-TSK-PERF T-25): the nexus fetch is the one network call of a read, about 0.8 s here, and a slow round trip to GitHub gave a 4.4 s run with low CPU use.
