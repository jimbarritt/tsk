This release is the first of the re-created `jimbarritt/tsk` repository. It has the same code as 0.89.0.

- The history of `main` was rewritten, and the repository was created again. Commit hashes, tags and the release pages of the earlier repository do not exist in it.
- No commit contains the removed research note. Each commit names the robot that made it, or `Tsk Robot` when the ledger names no robot. The `Agent-Session` trailer replaces `Claude-Session`.
- The robot key file signs every commit.
- Earlier releases are not re-created. GitHub blocks the tags of the immutable releases of the earlier repository.
- `tsk self-update`, the Homebrew formula and the install script read the archives of this release.
