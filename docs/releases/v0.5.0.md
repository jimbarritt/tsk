One command wires tsk into Claude Code, including in a Claude Code cloud session.

- `tsk install-plugin claude-cli` now writes the `SessionStart` hook into `.claude/settings.json`. `--no-hook` skips it, and a user-scope install never writes it.
- `tsk thread session-start --install-plugin claude-cli` installs the plugin first when `CLAUDE_CODE_REMOTE=true`. A failed step adds a warning to the session context.
