`tsk actor list` shows which robots are in use, the tmux chooser has columns, and the SessionEnd hook exits at once.

- **A state column in `tsk actor list`.** The columns are now name, kind, state, uid and instances. A robot is `free`, `taken (tmux pane)`, `taken (session <id>)` or `unknown`; a human has `-`. In a terminal the state comes from this machine's liveness files and tmux panes. In a cloud session it needs `--open <id>,...`, as `tsk thread next` does, else it is `unknown`. `--json` adds `state`.
- **Columns in the tmux chooser.** tmux prints the session name before the format, so the format starts with spaces that make the name 18 characters wide. The mission name is padded to 24 characters and the robot to 32, so the robot and the directory line up on every line. Needs tmux 3.2 or later. Run `tsk tmux install` again to write the new format.
- **The SessionEnd hook exits at once.** Claude Code cancels a SessionEnd hook that still runs when it exits ("Hook cancelled"). The hook records the end, then starts `tsk ledger push --background` and exits, so the push runs detached.
