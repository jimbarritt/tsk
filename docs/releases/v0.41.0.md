The ledger is at layout 14: a document carries its own identity in its file name (M-TSK-ADHOC, `docs/domain/urn-scheme.md`). The ledger changes at the first write by this `tsk` that needs the new layout, which includes a `doc put`, `doc mv` or `doc rm`. A `tsk` older than 0.41.0 then stops with `unsupported ledger version 14`. From 0.18.0 a `tsk` updates itself and runs the command again. A session start never upgrades.

- **A document has an id.** The file name ends in 8 lowercase hexadecimal characters before the last extension: `missions/x/report.3f2a9c1e.md`. `tsk ledger doc put missions/x/report.md` mints the id for a new path and prints the path it wrote. A second `doc put` of the path without the id rewrites the same file. A path with the id works as it is.
- **Every doc command takes the path with the id, without it, or the id alone.** This covers `doc get`, `doc rm`, `doc path`, `doc mv` and `tsk mission link`.
- **A link names the id.** `mission_documents` gains `doc_id`. `path` stays, as the current path of the file. `tsk ledger doc mv` renames the file, keeps the id, and updates `path` in every mission that links it, so a rename loses no link.
- **URNs.** `tsk mission list <id> --json` prints `id` and `urn` (`urn:tsk:document:<ledger-id>:<id>`) beside `path` and `role` for each linked document. `tsk ledger doc list` prints the id beside the path, and `--porcelain` separates them with a tab.
- **The upgrade is the same on every clone.** An existing document gets the first 8 hexadecimal characters of the MD5 of `urn:tsk:document-path:<path>`. The Dolt change updates `mission_documents` and the thread briefing paths. The first `doc put`, `doc mv`, `doc rm` or push on a ledger at layout 14 renames the files that have no id, once; a file that has an id is left alone. A read renames nothing. Two clones that upgrade on their own make the same change and merge. `docs/domain/ledger-layout.md` describes both parts.
- Plugin 0.3.42: the `tsk` skill names the new doc commands. The plugin requires tsk 0.41.0 or later.
- Tests: the upgrade of a layout 13 ledger on two clones gives the same ids and merges, a put mints an id and a second put by the path without it rewrites the same file, a move keeps the id and the links, get and path work by id, and the JSON of a mission shows the document URN. Every test that names a document path takes the id into account.
