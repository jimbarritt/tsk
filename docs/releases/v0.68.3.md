`tsk harness wake` takes the claude session to resume from the ledger.

- **Session resume from the ledger.** `tsk harness wake` reads the `sessions` table for the latest claude session of the harness worktree. It starts claude with `--resume <id>` when the transcript of that session exists. Otherwise it starts a new session with `--session-id`. The harness state no longer records a session ID, so a harness made before 0.68.2 resumes too. A session that `/clear` starts is the one that resumes. A state file that still has the field loads. The first prompt of `wake` runs `/tsk:resume-thread` on both paths. The session start hook does not record the session as the holder of the thread.
