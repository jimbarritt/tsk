Verifiable robot commits (M-TSK-ATTRIB T-14). `tsk actor git-identity` writes an allowed signers file, so `git log --format=%G?` prints `G` for a robot commit in any session. The ledger stays at layout 14, and the plugin stays at 0.3.45.

- **`tsk actor git-identity` writes `robot-allowed-signers`.** The file holds the robot email and the public key of `TSK_ROBOT_SIGNING_KEY`, which the command derives with `ssh-keygen -y`. It sits beside the key file, outside the repo.
- **It sets `gpg.ssh.allowedSignersFile`** in the worktree config. Without it git cannot verify an SSH signature and prints `N`.
- **The command exits 1 when `ssh-keygen` is missing** and names `openssh-client`.
- User guide: [docs/user-guide/robot-commit-signing.md](../user-guide/robot-commit-signing.md).
- Tests: the attribution unit tests. A manual test in a cloud session: after the command runs, `git log -1 --format=%G?` prints `G` for a commit signed with the robot key.
