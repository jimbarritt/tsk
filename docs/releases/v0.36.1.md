A `/tsk:self-update` skill (M-TSK-ADHOC T-36). The ledger is still at layout 10.

- **The fault.** `/tsk:self-update` did not appear in a terminal Claude Code session, because the plugin had no skill for it. `tsk self-update` is a command of the binary.
- **The skill.** `/tsk:self-update` reads `tsk --version`, runs `tsk self-update --check`, runs `tsk self-update` when a newer release exists, reads the version again and reports the old and the new version. It says that the plugin and the hooks of the session change at the next session start, and points to `tsk doctor` when another `tsk` on `PATH` shadows the new one.
- Plugin 0.3.33. The plugin still requires tsk 0.36.0 or later.
