The session environment now supplies the robot's git identity and signing settings, not a git config file.

- **Robot attribution in the session environment.** The session start writes `export` lines to the file named by `CLAUDE_ENV_FILE`. They set the author, the committer and the signing settings. It replaces the lines it wrote on every source and keeps other lines unchanged. A person's commit in the same checkout keeps the person's own identity. The commit-msg hook finds the session from `TSK_SESSION`. It adds the `Co-authored-by` trailer when a human joined that session. `tsk actor git-identity` prints the lines and writes nothing. The session start removes a robot set-up that an older tsk wrote to a worktree config.
