`tsk mission rewrite` replaces an old mission ID in the text of every mission. The ledger is still at layout 10.

- **The need.** A rename changes the ID of a mission and every key that names it. Free text keeps the old ID: decisions, constraints, out-of-scope items, objectives, answered questions, purposes and task descriptions. There was no command to edit most of those records.
- **The command.** `tsk mission rewrite <old> <new> [--dry-run]` replaces `<old>` with `<new>` as a whole word in the name, purpose, decision authority, objectives, constraints, out-of-scope items, tasks, decisions, questions and answers of every mission. `<old>` can be the ID of a mission renamed earlier. `<new>` has to be a mission. It prints `rewrote <mission> <record>` for each change.
- **With a rename.** `tsk mission mv <old> <new> --rewrite` renames, then rewrites. In a dry run it prints the `rewrote` lines in place of the `mentions` lines.
- Documents are not changed.
- Tests: `cli/src/mission/mv.rs` (whole-word replacement and every record kind) and `cli/tests/conformance.rs` (the command, a dry run, a second run, an unknown `<new>`).
- The plugin requires tsk 0.32.0 or later.
