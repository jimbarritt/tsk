`tsk nexus move-ledger` copies a repo's existing ledger, records and documents, from the repo's own branches to the attached nexus, and points the repo at the copy (M-TSK-JIM-BOOT T-03).

- **The command.** It stops when the ledger store on this machine has changes that origin does not have, or when origin cannot be checked. It copies origin's ledger ref and documents ref, with their full history, to `ledgers/<repo-id>` and `ledgers/<repo-id>-docs` in the nexus, then sets the repo's entry in `nexus.json` to `"ledger": "nexus"` with `ledger_refs` and the mission prefix. It adds the entry when the nexus has none.
- **Safe to run again.** The command skips a nexus ref that already points at the same commit. A nexus ref that points at a different commit stops the command, and nothing is written.
- **The old refs stay.** The command does not delete the refs on origin. It prints the `git push origin --delete` command for them.
- **`--ledger-refs`** chooses branches or a custom ref in the nexus. It defaults to the refs the ledger uses now. `--id` and `--territory` work as in `register-repo`.
- **Docs:** `docs/user-guide/nexus-quickstart.md` has a section on moving an existing ledger.
- **Tests:** three end to end tests (the move with a read and a push from the same clone and a new clone, the error with unpushed changes, the error when the nexus has a different ledger) and four unit tests for the `nexus.json` edit.
